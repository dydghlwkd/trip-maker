# 여행 페이지 메이커

목적지, 날짜, 항공·숙소, 날짜별 장소를 넣으면 여행 페이지를 만들어 주는 웹앱이에요.

- 국내 여행은 카카오맵, 해외 여행은 구글맵으로 장소와 길찾기를 열어요.
- 여행은 각자 브라우저에만 저장돼요. 서버가 없어요.
- "공유 링크 복사"로 여행을 링크 하나에 담아 보낼 수 있어요.
- "HTML 파일로 저장"하면 인터넷 없이도 열리는 파일이 돼요.
- 휴대폰 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있어요.

파일 하나(`index.html`)로 된 정적 사이트라 GitHub Pages에 그대로 올리면 돼요.
